# 🐍 Full-Stack Python – 60 Days Challenge 🚀

This repository contains my **#60DaysOfPython Challenge**, where I learned Python deeply for 60 days.

---

## 📂 60DaysOfPython

- 📘 **Day 1–10: Python Basics**
  - Introduction to Python → History, features & why Python is popular.
  - Variables & Data Types → Numbers, strings, boolean, dynamic typing.
  - Operators & Expressions → Arithmetic, relational, logical, bitwise.
  - Input & Output → Taking user input & printing formatted output.
  - Conditional Statements → if, elif, else for decision making.
  - Loops → for, while for repetition.
  - Break, Continue, Pass → Control flow modifiers.
  - Functions → Reusable code blocks, args, kwargs, return values.

- 📗 **Day 11–20: Data Structures**
  - Strings → Immutable sequences, slicing, methods.
  - Lists → Ordered, mutable collections with indexing.
  - Tuples → Ordered, immutable collections.
  - Sets → Unordered collections of unique items.
  - Dictionaries → Key-value mappings, methods.
  - Comprehensions → One-line way to build list, dict, set.

- 📙 **Day 21–30: Advanced Python Concepts**
  - Modules & Packages → Code reusability, import system.
  - Exception Handling → try, except, finally, raising errors.
  - File Handling → Reading/writing text, CSV files.
  - Iterators & Generators → Memory-efficient looping.
  - Decorators → Modifying function behavior dynamically.
  - Lambda Functions → Anonymous, single-line functions.

- 📕 **Day 31–40: Object-Oriented Programming (OOP)**
  - Classes & Objects → Blueprint of real-world entities.
  - Constructors & Destructors → __init__(), __del__().
  - Inheritance → Reusing code across classes.
  - Encapsulation → Hiding implementation, protecting data.
  - Abstraction → Showing essential features only.
  - Polymorphism → Many forms (method overriding/overloading).
  - Garbage Collector → Memory management in Python.

- 📒 **Day 41–50: Python for Real-world Usage**
  - 🗄️ PDBC (Python Database Communication) → Connecting Python with DB.
  - 📑 File Handling (CSV, JSON, XML) → Data storage & transfer formats.
  - ⚡ Multithreading & Multiprocessing → Parallel execution.
  - 🛠️ Useful Modules → OS, Sys, Math, Datetime basics.
  - 🔍 Regular Expressions (Regex) → Searching & text processing.

- 📔 **Day 51–60: Regex & JSON**
  - Regex Deep Dive
    - match(), search(), findall(), finditer() → Pattern matching.
    - sub(), split(), compile() → Replace & split by regex.
    - Character Classes → [a-z], [0-9], [^abc].
    - Predefined Classes → \d, \w, \s and their opposites.
    - Quantifiers → *, +, ?, {n}, {n,m}.
  - JSON in Python
    - json.loads(), json.dumps() → String ↔ Dict.
    - json.load(), json.dump() → File ↔ Dict.
    - Handling real-world JSON data.
  - Wrap-up & Key Learnings → Strong base in Python fundamentals.

- ✅ **Completion**
  - 60 Days of Consistency & Discipline
  - 🏆 Strong Python Foundation
  - 🌟 Ready to dive into Data Science 🚀
